# Ration Reg updates

This public repository hosts the Ration Reg Android and Windows app installers and `releases/latest.json`, which installed apps check for newer versions.

The stock records, spreadsheet IDs, connection keys, signing keys, and Apps Script code are not stored here.

Installers are built from the local Ration Reg project. Install the first updater-enabled version manually; later versions appear in the app's update check.
